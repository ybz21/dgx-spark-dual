## 没做的事

- **没有启动服务**。这台机器上还跑着 blade 系列生产容器（`box-bos`、`box-llm-gateway`、
  `box-gitea` 等），拉起 DeepSeek 会吃掉大部分统一内存，属于会影响他人的操作，留给人工决定。
- **没有验证 `MAX_NUM_SEQS=12` / `gmu=0.85` 的长时稳定性**。这两个值与上游"当前最佳"
  （6 / 0.78）不一致，上游明确说 0.80 以上会"启动正常、smoke 正常、真实流量下挂掉"。
  详见主 README 的"待确认"一节。
